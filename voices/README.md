# Individual voice clips

Short (~15-20s) individual audio clips linked from each portrait's "Listen"
link on an event page — distinct from the full combined montage in
`../montages/`. For a real event, this would typically just be that
person's actual Drive recording link (already captured in the Sheet at
submission time) rather than a separately-hosted file; these exist here
specifically for the demo event, where the placeholder source recordings
were far longer than a real ~2-minute submission would be, so a short
extracted highlight makes more sense to link to than the full original.
